# day24-register-file-verilog-genus
Design and verification of an 8×8 register file using Verilog HDL with one synchronous write port and two asynchronous read ports. Includes a self-checking testbench, Cadence NCSim simulation (292 checks passed, 0 errors), Cadence Genus synthesis, standard-cell area and power analysis, and setup timing investigation using the TSMC 180 nm library.
